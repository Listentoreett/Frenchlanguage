# Week 3 – Job Search and Interviews in French

## Goal
By the end of this week, you should be able to:
- understand common job advertisements
- write a basic CV and cover letter in French
- answer basic interview questions
- talk about skills, experience, and availability
- speak professionally and politely

## 6. Writing a basic CV in French

### Typical CV sections
- Informations personnelles
- Expérience professionnelle
- Formation
- Compétences
- Langues
- Centres d’intérêt

### Example
- Nom: Jean Martin
- Nationalité: Française / étrangère
- Langues: Français, anglais
- Expérience: 2 ans dans le commerce
- Compétences: service client, gestion, travail d’équipe

## 7. Cover letter formula

- Bonjour,
- Je vous remercie pour l’opportunité.
- Je souhaite postuler pour le poste de ...
- J’ai de l’expérience dans ...
- Je suis motivé(e) par ...
- Je suis disponible à partir de ...
- Je vous remercie de votre considération.
- Cordialement,
